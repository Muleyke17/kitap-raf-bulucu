# kitap-raf-bulucu
PHP ve MySQL ile geliştirilmiş kütüphane veya kitap dükkanında kullanılabilecek temel seviye raf sistemi geliştirilmiştir. Bu projede eklenen kitapları barkod veya adıyla aratıp hangi rafta olduğunu bulabilir satılmayan veya tükenen kitapları silebilir ya da yeni gelen bir kitabı sisteme ekleyebilirsiniz.
